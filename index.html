HARDWARE SETUP

Wire MPU6050 to nRF52833 DK:

  • VCC → 3.3V
  • GND → GND
  • SDA → P0.26 (configure in DTS overlay)
  • SCL → P0.27 (configure in DTS overlay)
  • AD0 → GND → I²C address 0x68

BLE DEVICE NAME

Set CONFIG_BT_DEVICE_NAME="mpu6050 data" in your prj.conf. The web app filters by this name exactly.

CONNECTING

  1. Click Connect BLE — a browser dialog appears.
  2. Select mpu6050 data from the list.
  3. Press START to begin data streaming.
  4. Live charts and the table update in real time.
  5. Press STOP — a save dialog appears.

SAVE DIALOG

After stopping you can:

  • ↗ Save to Drive — uploads CSV to MPU6050 Data folder in Google Drive.
  • ↓ Save Locally — downloads CSV to your computer.
  • ✕ Discard — clears the session without saving.

Filename pattern: {label}_{wheel}_{timestamp}.csv

GOOGLE APPS SCRIPT SETUP

One-time setup to enable Drive saving. No OAuth popup — works instantly on any network.

  1. Go to script.google.com → New Project.
  2. Paste the doPost / doGet code provided.
  3. Click Deploy → New deployment.
  4. Type: Web app.
  5. Execute as: Me (sanjeetathawale21@gmail.com).
  6. Who has access: Anyone ← critical for CORS.
  7. Click Deploy → copy the Web App URL.
  8. Paste it into APPS_SCRIPT_URL in index.html.

Files save automatically to MPU6050 Data folder in that Google account.
