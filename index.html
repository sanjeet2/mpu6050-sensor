MULTI-BOARD SETUP

Each board must have a unique BLE name in prj.conf.

BoardBLE name
nRF52833 DKCONFIG_BT_DEVICE_NAME="nrf33"
nRF52840 DKCONFIG_BT_DEVICE_NAME="nrf40"

HOW TO USE

  1. Click Connect Board and connect nrf33.
  2. Click Connect Board again and connect nrf40.
  3. Click Start All to start both.
  4. Click Stop All to stop both.
  5. Save popup will come one-by-one for each board.

SCALING

Add more BLE names in the BOARDS object. Example:

'nrf41': { label: 'Wheel 3', color: '#ffd700' }
